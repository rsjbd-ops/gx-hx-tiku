# 广西航线刷题

广西内河船员航线考试刷题程序（南宁 → 贵港 → 白马大角 → 梧州）。

- 打开方式：直接访问本仓库的 GitHub Pages 网址，或在本地双击 `index.html`
- 题库：297 题，按 3 条航线 / 15 个航段分章
- 特点：答完一题立即显示对错与正确答案，支持顺序 / 随机 / 错题三种模式
- 图片：246 道题配有电子航道图、航道图摘录或实景照片，来自原试卷

## 目录

```
index.html     刷题程序（单文件，无外部依赖）
images/        题目配图（WebP，600px 宽）
```

## 说明

题目与答案整理自航线题库表格，并用原在线试卷的答案逐题核对。
仅用于个人学习复习。
